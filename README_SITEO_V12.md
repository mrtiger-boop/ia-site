# Siteo V12 Complet

Cette version garde le projet complet hors `.env`, `.git` et `node_modules`, puis ajoute :
- 120 templates dans `public/assets/templates-v12.json`
- 24 assets SVG dans `public/assets/`
- pages : Marketplace, Showcase, Analytics, Settings
- design premium
- feuilles ON/OFF
- génération IA, Stripe, Supabase

## Tester

```bash
npm install
npm start
```

Puis ouvre :

```txt
http://localhost:3000
```
