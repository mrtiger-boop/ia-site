💡 Exemple de prompt

Créer un site portfolio premium pour un développeur Roblox.

Style : bleu et vert, moderne, professionnel, avec animations douces.

Sections :
- Accueil avec gros titre
- À propos
- Compétences
- Projets Roblox
- Services
- Contact

Ajouter :
- cartes premium
- boutons arrondis
- design responsive mobile et PC
- footer propre

Créer index.html, style.css et script.js.

📦 Utiliser le ZIP

  1. Télécharge le ZIP.
  2. Fais clic droit puis extraire.
  3. Garde index.html, style.css et script.js ensemble.
  4. Double-clique sur index.html.

🚀 Mettre en ligne

  1. Crée un repo GitHub.
  2. Ajoute les 3 fichiers.
  3. Sur Render, choisis Static Site.
  4. Publish Directory : .
