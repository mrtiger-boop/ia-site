💡 Comment écrire un bon prompt ?

Plus tu donnes de détails, meilleur sera le site généré.

1. SujetExplique le type de site : portfolio, boutique, blog, restaurant, Roblox...
2. StyleIndique l’ambiance : premium, naturel, bleu/vert, médiéval, pâtisserie...
3. SectionsListe les pages ou blocs : accueil, services, tarifs, contact, galerie...
4. FonctionsDemande formulaire, animations, filtres, FAQ, boutons, responsive mobile...

Exemple à copier :

Créer un site portfolio premium pour un développeur Roblox.

Style : bleu et vert, moderne, professionnel, avec animations douces.

Sections :
- Accueil avec gros titre
- À propos
- Compétences
- Projets Roblox
- Services
- Contact

Ajouter :
- cartes premium
- boutons arrondis
- design responsive mobile et PC
- footer propre

Créer index.html, style.css et script.js.

📦 Comment utiliser le ZIP téléchargé ?

  1. Clique sur Télécharger ZIP.
  2. Fais clic droit sur le ZIP puis Extraire tout.
  3. Garde les 3 fichiers dans le même dossier : index.html, style.css, script.js.
  4. Double-clique sur index.html pour ouvrir le site.

Important : ne sépare pas les fichiers. Le HTML utilise style.css pour le design et script.js pour les interactions.

🚀 Comment mettre ton site généré en ligne ?

  1. Extrais le ZIP généré.
  2. Vérifie que index.html, style.css et script.js sont ensemble.
  3. Crée un repo GitHub et ajoute les 3 fichiers.
  4. Sur Render, choisis Static Site pour un simple site HTML/CSS/JS.
  5. Build Command : laisse vide. Publish Directory : .

Pour un projet Node.js comme Siteo lui-même, il faut utiliser Web Service avec npm install et npm start.
